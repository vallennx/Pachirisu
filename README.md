# 🐿️ Pachirisu

**Pachirisu** is a Discord bot that runs [Pokétwo](https://poketwo.net) **mass incense** events for you. It pauses and resumes incense channels, tracks spawns, runs live slot boards, manages reserves, posts shiny / Gigantamax / IV catch alerts, and can even help set up your server's channels, so organizers can focus on the fun part.

## ✨ Features

| Area | What it does |
|---|---|
| **Incense control** | Watch channels, auto-pause the moment someone buys an incense, resume manually or on a timer, block Pokétwo commands in paused channels, and notify members when channels reopen. |
| **Incense monitor & live board** | Tracks spawns remaining and end times per channel, and keeps a continuously updated status board. |
| **Slot boards** | Interactive boards (buttons / Components V2) where members grab, leave, split, and swap slots. Boards survive bot restarts. |
| **Reserves** | Add / remove / donate reserves, category reserves (rares, regionals, eevos, …), gifting reserves to others, and optional [Hatenna](https://hatenna.xyz/) Organizer API sync. |
| **Server setup** | Help set up your server for events: create, rename and organize channels and categories (limits depend on your premium tier). |
| **Templates** | Save and load slot layouts for repeat events. |
| **Automated hosting** | Reaction-based start, announcements, and ready-up checklists. |
| **Starboard** | Shiny, Gigantamax, high-IV, low-IV, and MissingNo. catch alerts with fully customizable messages and embeds. |
| **Announcements** | Build reusable announcements and congrats messages with variables. |
| **Roles & permissions** | Organizer roles, bot-admin role, per-server confirmation prompts, incense bans. |
| **Premium tiers** | Comet → SuperNova tiers raise watch-channel / channel-creation / template limits (currently free). |

Run `-help` in a server for the full command list, or `-guide` for the interactive walkthrough.

## 🚀 Quick start

1. Invite Pachirisu with the link above.
2. Give it these permissions (they are what the features need): **View Channels, Send Messages, Send Messages in Threads, Send TTS Messages, Embed Links, Attach Files, Read Message History, Use External Emojis, Add Reactions, Manage Messages, Manage Channels, Manage Roles, Ban Members, Mention @everyone/@here/All Roles**.
3. In Server Settings → Roles, drag Pachirisu's role **above** the roles it needs to manage (for example your organizer and IncBan roles).
4. Use `-help` to see commands. The default prefix is `-`.
